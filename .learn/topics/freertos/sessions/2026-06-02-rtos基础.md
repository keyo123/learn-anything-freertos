# 会话记录: RTOS 基础概念

日期: 2026-06-02
概念: 什么是 RTOS、裸机 vs RTOS、任务状态机、调度机制

## 覆盖内容

1. **裸机 vs RTOS**
   - while(1) 超级循环的局限性——所有任务串行，阻塞导致全局延迟
   - RTOS 将功能拆分为独立任务，调度器管理执行顺序

2. **关键思维转变**
   - 裸机：开发者控制调用顺序
   - RTOS：调度器决定执行顺序
   - 延时 vs 让出 CPU（vTaskDelay 非忙等）

3. **任务状态机**（就绪态、运行态、阻塞态、挂起态）

4. **调度机制**
   - SysTick 定时器作为调度心脏
   - vTaskDelayUntil 保证精确周期
   - 抢占式调度：高优先级任务就绪时立即切换
   - 时间片轮转：同级任务轮流执行（1 Tick/次）
   - 空闲任务：所有任务阻塞时运行

5. **温控实例分析**
   - 传感器 10ms / 屏幕 100ms / SD 卡 1s 三任务
   - 首次执行：依次创建，传感器先跑
   - t=100ms 竞争：传感器 vs 屏幕（同级轮转）
   - SD 卡在 t=1000ms 才参与调度

## 用户基础

具备裸机开发经验，了解基本操作系统概念但不深入。
